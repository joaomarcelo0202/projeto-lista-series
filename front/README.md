# Front

Front em Vue que consome a [API](../api) do projeto. É o desafio do trabalho: usar a API em outro projeto, com outro framework.

Na tela dá pra buscar séries na TVmaze, adicionar na lista, marcar como visto e remover.

## Como rodar

A API precisa estar rodando em `http://127.0.0.1:8000`.

```bash
npm install
npm run dev
```

Depois abrir `http://localhost:5173`.
